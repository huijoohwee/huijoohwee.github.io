# Project Rules Mantras Module

## Scope and Ownership

This optional presentation module belongs to [Project Rules](./project-rules.md).
The [shared CID contract](./cid-guidelines.md) owns the field meanings and composition rule.

## Three-Beat Mantra Form

Render an existing directive as `Context; Intent; Directive`, preserving its scope and qualifiers.
Resolve the source reference before using the phrase as an instruction. Do not turn conditional
requirements into universal prohibitions or invent a second policy list.

Example presentation of the resource rule in [Project Rules](./project-rules.md#performance--quality-directives):

> Selected check; obtain relevant evidence efficiently; acquire only its required capabilities.

Use the full source when the compressed wording omits a prerequisite, authority boundary or check.
